# PostgreSQL Backup Manager - Документация

## Обзор проекта

PostgreSQL Backup Manager — это полнофункциональное приложение с графическим интерфейсом для Windows, предназначенное для резервного копирования и восстановления нескольких баз данных PostgreSQL, а также для настройки автоматического расписания этих операций.

## Архитектура приложения

### Основные компоненты

1. **main.py** - Основной файл приложения, содержащий:
   - Классы рабочих потоков для выполнения операций без блокировки UI
   - Вкладки интерфейса (подключение, резервное копирование, восстановление, расписание)
   - Логику взаимодействия с PostgreSQL утилитами

2. **build_exe.py** - Скрипт для сборки standalone-исполнимого файла

3. **requirements.txt** - Зависимости приложения

4. **README.md** - Инструкция по использованию

5. **setup.bat** - Скрипт запуска для Windows

## Функциональные возможности

### 1. Подключение к PostgreSQL
- Поля ввода: хост, порт, пользователь, пароль
- Кнопка проверки подключения
- Автоматический поиск PostgreSQL инструментов
- Поддержка всех необходимых утилит (pg_dump, pg_restore, psql, pg_isready)

### 2. Резервное копирование
- Выбор нескольких баз данных из списка
- Ручной ввод имен баз через запятую
- Поддержка двух форматов:
  - SQL (plain) - для совместимости с pgAdmin и psql
  - Custom (.backup) - для pg_restore
- Указание директории для резервных копий
- Автоочистка старых резервных копий (настраиваемое количество)
- Прогресс-бар и подробный лог выполнения

### 3. Восстановление
- Выбор файла резервной копии через диалог
- Автоматическое определение исходной базы из имени файла
- Защита от случайной перезаписи с подтверждением
- Поддержка обоих форматов (.sql и .backup)
- Прогресс-бар и подробный лог

### 4. Планировщик заданий
- Создание заданий в Windows Task Scheduler
- Настройка периодичности (ежедневно/еженедельно)
- Указание времени запуска
- Управление заданиями (создание, удаление, просмотр)

## Безопасность

- Пароли не сохраняются в приложении
- Пароли передаются через переменную окружения PGPASSWORD
- Переменная окружения удаляется сразу после использования
- При планировании заданий пароль запрашивается при каждом запуске

## Технические особенности

### Графический интерфейс
- На русском языке
- Четкая навигация по вкладкам
- Адаптивный дизайн
- Поддержка масштабирования DPI
- Визуальные элементы прогресса
- Понятные сообщения об ошибках

### Архитектура потоков
- Все операции выполняются в отдельных потоках
- UI не блокируется во время выполнения задач
- Потоки для: проверки подключения, получения списка баз, резервного копирования, восстановления

### Совместимость
- Windows 7 и выше
- Python 3.8+
- PostgreSQL 9.0 и выше

## Сборка приложения

Для сборки standalone-исполнимого файла используется PyInstaller:

```bash
python build_exe.py
```

Результат сборки сохраняется в папке `dist/PostgreSQL_Backup_Manager.exe`

## Использование

1. Запустите исполняемый файл `PostgreSQL_Backup_Manager.exe`
2. Перейдите на вкладку "Подключение"
3. Введите параметры подключения к PostgreSQL
4. Нажмите "Проверить подключение"
5. Используйте другие вкладки для резервного копирования, восстановления или настройки расписания

## Требования к системе

- Операционная система: Windows 7 или выше
- PostgreSQL клиентские утилиты: pg_dump, pg_restore, psql, pg_isready
- Для запуска из исходного кода: Python 3.8+

## Особенности реализации

- Полностью на русском языке (интерфейс, сообщения, подсказки)
- Современный GUI с использованием PyQt6
- Компилируется в автономный .exe-файл через PyInstaller
- Все зависимости и ресурсы включены в исполняемый файл
- Безопасная работа с паролями
- Поддержка всех необходимых функций согласно требованиям
