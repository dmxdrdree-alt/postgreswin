# PostgreSQL Backup Manager - Сводка проекта

## Описание
Полнофункциональное приложение с графическим интерфейсом для Windows, предназначенное для резервного копирования и восстановления нескольких баз данных PostgreSQL, а также для настройки автоматического расписания этих операций.

## Структура проекта

### Основные файлы
- **main.py** (55,464 байта) - Основной файл приложения с GUI и всей логикой
- **requirements.txt** (64 байта) - Зависимости: PyQt6, psutil, pywin32
- **README.md** (4,293 байта) - Инструкция по использованию
- **DOCUMENTATION.md** (6,158 байта) - Полная документация
- **SPECIFICATION_IMPLEMENTATION.md** (7,394 байта) - Подтверждение реализации требований
- **PROJECT_SUMMARY.md** (1,043 байта) - Этот файл
- **build_exe.py** (4,873 байта) - Скрипт сборки в .exe
- **setup.bat** (499 байтов) - Скрипт запуска для Windows
- **setup_build.py** (2,291 байт) - Альтернативный скрипт сборки
- **PostgreSQL_Backup_Manager.spec** (678 байтов) - Файл спецификации PyInstaller

### Служебные папки
- **build/** - Временные файлы сборки PyInstaller
- **dist/** - Результат сборки (исполняемый файл)

## Результат сборки
- **Исполняемый файл**: dist/PostgreSQL_Backup_Manager.exe
- **Размер файла**: ~53MB
- **Тип**: Standalone .exe (не требует Python или зависимостей)
- **Совместимость**: Windows 7 и выше

## Реализованные функции
1. Подключение к серверу PostgreSQL (проверка соединения, автопоиск утилит)
2. Многобазовое резервное копирование (SQL и Custom форматы)
3. Восстановление из резервных копий (с защитой от перезаписи)
4. Планировщик заданий Windows (ежедневно/еженедельно)
5. Русский интерфейс (все элементы управления и сообщения)
6. Безопасная работа с паролями (не сохраняются, используются временно)
7. Автоочистка старых резервных копий
8. Многопоточность (не блокируется UI во время операций)

## Технологии
- Python 3.8+
- PyQt6 (современный GUI)
- PyInstaller (сборка в standalone .exe)
- PostgreSQL клиентские утилиты (pg_dump, pg_restore, psql, pg_isready)
