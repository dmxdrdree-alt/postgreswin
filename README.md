# PostgreSQL Backup Manager

## Описание
PostgreSQL Backup Manager — это приложение с графическим интерфейсом для Windows, предназначенное для резервного копирования и восстановления нескольких баз данных PostgreSQL, а также для настройки автоматического расписания этих операций.

## Особенности
- Удобный графический интерфейс на русском языке
- Подключение к серверу PostgreSQL с проверкой соединения
- Многобазовое резервное копирование с поддержкой SQL и custom форматов
- Восстановление из резервных копий с защитой от случайной перезаписи
- Планировщик заданий Windows для автоматизации резервного копирования
- Автоматическая очистка старых резервных копий
- Безопасная работа с паролями (не сохраняются в файле)

## Требования
- Windows 7 или выше
- PostgreSQL клиентские утилиты (pg_dump, pg_restore, psql, pg_isready)
- Python 3.8 или выше (для исходного кода)

## Установка и запуск

### Вариант 1: Из исходного кода
1. Установите Python 3.8+
2. Установите зависимости: `pip install -r requirements.txt`
3. Запустите приложение: `python main.py`

### Вариант 2: Из собранного .exe файла
1. Скачайте готовый исполняемый файл `PostgreSQL_Backup_Manager.exe`
2. Запустите его двойным кликом

## Использование

### Подключение
1. Введите параметры подключения к серверу PostgreSQL (хост, порт, пользователь)
2. Введите пароль
3. Нажмите "Проверить подключение"
4. При необходимости укажите путь к PostgreSQL инструментам (или используйте автопоиск)

### Резервное копирование
1. Перейдите на вкладку "Резервное копирование"
2. Выберите базы данных из списка или введите вручную
3. Укажите параметры резервного копирования:
   - Формат: SQL или Custom
   - Директория для сохранения резервных копий
   - Максимальное количество копий на базу
4. Нажмите "Начать резервное копирование"

### Восстановление
1. Перейдите на вкладку "Восстановление"
2. Выберите файл резервной копии
3. Укажите целевую базу данных для восстановления
4. Если происходит восстановление поверх исходной базы, подтвердите действие
5. Нажмите "Начать восстановление"

### Расписание
1. Перейдите на вкладку "Расписание"
2. Укажите параметры задания:
   - Имя задания
   - Периодичность: ежедневно или еженедельно
   - Время запуска
3. Нажмите "Создать задание" для добавления в планировщик Windows

## Безопасность
- Пароли не сохраняются в приложении
- Пароли передаются через переменную окружения PGPASSWORD и удаляются после использования
- При планировании заданий пароль запрашивается каждый раз при запуске
