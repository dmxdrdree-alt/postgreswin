# PostgreSQL Backup Manager

## Описание
PostgreSQL Backup Manager — это приложение с графическим интерфейсом для Windows, которое позволяет создавать резервные копии баз данных PostgreSQL и управлять расписанием архивации.

## Функциональность

### Подключение к PostgreSQL
- Поля ввода для: хоста, порта, имени БД, пользователя
- Ввод пароля без сохранения (временное использование через переменную окружения PGPASSWORD)
- Кнопка «Проверить подключение» (запускает pg_isready или простой запрос через psql)

### Резервное копирование
- Выбор формата: plain SQL (.sql) или custom (.backup)
- Указание пути к папке для хранения резервных копий
- Автоматическое именование файла: dbname_YYYYMMDD_HHMMSS.sql/.backup
- Ограничение количества сохраняемых копий (по умолчанию 10)
- Прогресс-бар и лог-окно с ходом выполнения и ошибками

### Расписание
- Возможность настроить периодическое резервное копирование через Планировщик заданий Windows
- Параметры: ежедневно/еженедельно, время запуска
- Кнопки: «Создать задание», «Удалить задание», «Просмотреть задания»

## Требования
- Windows 10/11
- Python 3.8+
- PostgreSQL (для использования pg_dump)

## Установка и запуск

### Для разработки (Windows):
```cmd
pip install -r requirements.txt
python main.py
```

### Для сборки исполняемого файла:
#### Вручную:
```cmd
python build.py
```

#### Или с помощью скрипта:
```cmd
build.bat
```

После выполнения скрипта сборки исполняемый файл будет находиться в папке `dist/PostgreSQL_Backup_Manager.exe`.

## Использование

1. Запустите приложение
2. Введите параметры подключения к PostgreSQL (хост, порт, имя БД, пользователь, пароль)
3. Нажмите "Проверить подключение" для проверки соединения
4. Укажите папку для сохранения резервных копий
5. Выберите формат резервной копии
6. Нажмите "Создать резервную копию"

Для настройки расписания:
1. Выберите частоту (ежедневно/еженедельно)
2. Укажите время в формате HH:MM
3. Нажмите "Создать задание"

## Настройки
В разделе "Настройки" можно:
- Указать путь к pg_dump.exe вручную
- Изменить максимальное количество хранимых резервных копий

## Безопасность
- Пароль не сохраняется в настройках
- Переменная окружения PGPASSWORD очищается сразу после завершения операции
